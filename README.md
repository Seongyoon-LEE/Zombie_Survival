# 🚀 2D 좀비 TPS 서바이벌: Zombie Survival

**끊임없이 밀려드는 좀비 웨이브 속에서 단 한 자루의 총으로 살아남는 서바이벌 TPS 게임입니다.**

<br>

🎥 **게임 영상**  
https://youtu.be/v06FlqHdTTY

<br>

## ✨ 주요 기능

- **🔫 무기 데이터 관리**: ScriptableObject를 활용하여 다양한 총기 데이터를 손쉽게 관리  
- **🧩 유연한 구조**: `IDamageable` 인터페이스를 적용해 객체 간 느슨한 결합 구현  
- **👤 생명체 관리**: 모든 캐릭터는 `LivingEntity`를 상속받아 일관된 관리 가능  
- **🌐 멀티플레이 지원**: Photon 2 Networking을 통한 실시간 멀티플레이 구현  
- **🎨 그래픽 효과**: Post Processing을 통한 다채로운 화면 연출  
- **🎁 아이템 상호작용**: 필드에 드랍되는 다양한 아이템을 획득 및 활용 가능  

<br>

## 🛠️ 개발 환경

- **Engine**: Unity  
- **Language**: C#
